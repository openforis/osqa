{% trans "Variables and examples" %}

{% blocktrans %}The skin draws with CSS variables; changing one changes it everywhere. The main ones: --brand (links, buttons), --brand-dark (hover), --brand-soft (light highlights), --accent (the Ask button), --text, --muted, --border, --surface (boxes), --background (page), --radius, --font and --content-width.{% endblocktrans %}

{% example "css-example-colours" _("Colours for both themes") %} :root { --brand: #2d6a3e; --brand-dark: #1f4d2c; --brand-soft: #e9f3ec; } /* Dark theme: always :root[data-theme="dark"], never a media query. */ :root[data-theme="dark"] { --brand: #7fcf94; --brand-soft: #16281c; } {% endexample %} {% example "css-example-logo" _("A bigger, rounded logo") %} #logo img { max-height: 56px; border-radius: 8px; } {% endexample %} {% example "css-example-corners" _("Square corners on boxes and buttons") %} :root { --radius: 0; } input[type="submit"], input[type="button"], button, a.button { border-radius: 0; } {% endexample %} {% example "css-example-header" _("Style the custom header (Admin > Header and Footer)") %} #custom_header { padding: 6px 16px; background: var(--brand-soft); font-size: 13px; } {% endexample %}

{% blocktrans %}Check your changes on a phone-sized window and in the dark theme as well (the theme switch is in the footer). If your CSS assumes a light background, turn off dark mode under Look and feel.{% endblocktrans %}
